## 部署后验收顺序

1. 使用 HTTP 域名或服务器 IP 加端口部署，登录并核对两路频道；先使用中继订阅。需要 HTTPS 时自行配置 Nginx。
2. VLC 打开中天新闻，确认图像、声音、时间推进均正常，再验证东森新闻。
3. 出错时结合管理页状态、`docker compose logs --tail=100 app` 和 VLC 日志，区分来源解析、清单和媒体 CDN 请求问题。
4. 在电脑可访问 YouTube 时验证直连订阅；中继正常不代表直连一定可用。
5. 测试两台设备同频道及不同频道，观察 `docker stats`、流量与断线恢复；随后进行持续播放测试。
